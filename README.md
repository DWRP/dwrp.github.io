Welcome to my personal website! This repository contains the source code for my professional portfolio, where I introduce myself, showcase the technologies I use, my projects, and provide contact information.

## 🚀 Technologies Used

### Core
- **[Next.js 15.5](https://nextjs.org/)** - React framework with SSG/SSR capabilities
- **[React 19.2](https://react.dev/)** - JavaScript library for building user interfaces
- **[TypeScript](https://www.typescriptlang.org/)** - Typed superset of JavaScript

### UI/UX
- **[Tailwind CSS](https://tailwindcss.com/)** - Utility-first CSS framework
- **[Shadcn UI](https://ui.shadcn.com/)** - Reusable UI component library
- **[Framer Motion](https://www.framer.com/motion/)** - Animation library for React
- **[Lucide Icons](https://lucide.dev/)** - Modern icon library

### Internationalization
- **[next-intl](https://next-intl-docs.vercel.app/)** - Internationalization for Next.js
- Native support for 4 languages (en, pt-BR, es, zh-CN)

### DevOps
- **[GitHub Pages](https://pages.github.com/)** - Static site hosting
- **[GitHub Actions](https://github.com/features/actions)** - Automated CI/CD

## 🎯 Objective

Modern, high-performance personal portfolio website built with the latest web technologies. The project focuses on:

- **Performance**: Optimized static build with Next.js 15 and React 19
- **SEO**: Complete meta tags, Open Graph, Twitter Cards, and JSON-LD structured data
- **Accessibility**: WCAG compliant with semantic HTML and ARIA labels
- **Internationalization**: Full support for 4 languages
- **User Experience**: Smooth animations, theme switching, and responsive design

## ✨ Features

### Page Sections
- **🎨 Hero**: Introduction with career statistics and social links
- **👤 About**: Professional information and key competencies
- **💼 Experience**: Interactive timeline with detailed professional history
- **🛠️ Skills**: Technologies categorized by area (Frontend, Backend, Mobile, DevOps)
- **🎓 Education**: Academic background and professional certifications
- **🚀 Projects**: Featured projects showcase with filtering
- **📧 Contact**: Contact information and social media links

### Technical Features
- ✅ **Fixed Navigation**: Persistent menu with active section indicator
- ✅ **Responsive Menu**: Drawer navigation for mobile devices
- ✅ **Language Switcher**: Support for 4 languages with localStorage persistence
- ✅ **Theme Switching**: Dark/light mode with user preference
- ✅ **Smooth Animations**: Transitions and effects with Framer Motion
- ✅ **Complete SEO**: Meta tags, Open Graph, Twitter Cards, JSON-LD
- ✅ **Dynamic Sitemap**: Automatic generation for better indexing
- ✅ **Optimized Robots.txt**: Crawler configuration

## 🔧 Getting Started

### Prerequisites
- Node.js 18+ or higher
- Yarn or NPM

### Installation

```bash
# Clone the repository
git clone https://github.com/dwrp/dwrp.github.io.git

# Navigate to the directory
cd dwrp.github.io

# Install dependencies
yarn install
# or
npm install
```

### Development

```bash
# Start development server
yarn dev
# or
npm run dev

# Access http://localhost:3000
```

### Production Build

```bash
# Generate static build
yarn build
# or
npm run build

# Build output in /out directory
```
